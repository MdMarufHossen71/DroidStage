# Support

DroidStage is an early-stage open-source project and does not yet have a stable application release.

- **Bug reports:** use the Bug Report issue template and include reproducible steps.
- **Feature ideas:** use the Feature Request template.
- **Usage questions:** check the README and documentation first, then open a Discussion or issue if enabled.
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not publish vulnerabilities publicly.

Please include Windows version, browser/version, PC RAM, CPU, Android device model, Android version, and the exact DroidStage commit or release. Redact serial numbers, account names, IP addresses, and other personal identifiers.
